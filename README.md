# HealthTrack Management System

## 📖 Overview
HealthTrack is a full-stack health management system designed to simplify patient record management and healthcare workflows.  
It combines a **Spring Boot backend** with a **React.js frontend**, secured with **JWT authentication**, and powered by **PostgreSQL** for data persistence.  
Developed with **Copilot AI assistance** for optimized coding and documentation.

---

## 🛠 Tech Stack
- **Backend:** Java, Spring Boot, Hibernate/JPA, Spring Security (JWT), Swagger/OpenAPI  
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)  
- **Database:** PostgreSQL (Render Cloud DB)  
- **Testing:** JUnit 5, Mockito  
- **Deployment:** Docker, Render (backend), Vercel (frontend)  
- **Tools:** Maven, Git, Eclipse IDE, Copilot AI  

---

## ✨ Features
- 🔐 Secure user authentication & role-based access (JWT)  
- 📋 Patient record management (CRUD operations)  
- 📊 API documentation with Swagger/OpenAPI  
- 🗄️ PostgreSQL integration for scalable data storage  
- 🧪 Unit & integration testing with JUnit & Mockito  
- ⚡ Responsive React.js frontend with reusable components

## 🚀 Getting Started

### Prerequisites
- Java 17+
- Maven 3+
- Node.js & npm
- PostgreSQL
- Eclipse IDE (for backend)


### Backend Setup (Eclipse)
1. Open Eclipse → **Import Existing Maven Project** → select `healthtrack-backend`.  
2. Right‑click the project → **Run As → Spring Boot App** (or Java Application).  
3. Backend runs on **http://localhost:8081** by default. 


### Frontend Setup
cd healthtrack-frontend
npm install
npm start
